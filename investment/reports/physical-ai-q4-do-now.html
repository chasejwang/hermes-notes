§24 角色 · 4 行动 · 详细

① Tier 1 DATA · 黎曼 / RoboScience / 蚂蚁灵波

你是数据闭环派头部。资金厚，能直接建数据基础设施 + 自研大模型。

具体行动：
  • 数据基础设施 capex · 遥操作设备 30-40 万 × N 台 + 自动标注管线
  • 共同投资 + LTA · 参股数据采集公司 + 锁 2026 末 100 万小时
  • 统一中间表征专利 · VLOA / Object Trajectory / World Model · 行业标准
  • 商业化试点 · 国大药房 / 商超 / 物流 · 验证场景可复制性
② Tier 2 HARDWARE · 宇树 / 智元

你是本体派。IPO 已成 / 即将，硬件 + 资本强。但「融资补脑」是公开的秘密。

具体行动：
  • 抢数据源合作 · 与 Tier 1 签 LTA / 优先数据采购
  • 本体 + 模型双线 · 投资或自研 VLA 小模型
  • IPO 后 capex · 用上市资金建自有数据闭环
  • 垂直场景 · 工厂 / 物流 · 高 ROI 验证
③ Tier 3 STARTUP · 帕西尼 / 越疆 / 其他

你是零部件派或单点能力派。资金有限，等 LTA 排到你要 2028。

具体行动：
  • 等 2027 自托管 · Riemann-1.0 等开源 / API 化后接入
  • 单点深度 · 触觉 / 教育 / 医疗 · 利基市场
  • 合作 Tier 1 · 做上游配套 / 数据采集服务商
  • 关注应用层 · 仿真工具 / 评测平台 / 工具链
④ 个人 YOU · 决策层 / 资源有限的个人

你是个人决策者 / 投资者 / 求职者。资源有限但影响力高。集中在「决策 + 监控 + 调度」3 件事上。

具体行动：
  • 监控 6 个 RAG 信号 · 见 Q3 §3 · 决定跟哪条时间线
  • 投资视角 · Tier 1 数据闭环派是 LLM 时代「OpenAI」位置 · 优先关注
  • 求职 / 跳槽 · 物理 AI 是 Decision Scientist / AI-Augmented Decision Intelligence 的下一个 5 年蓝海
  • 消费 / 决策 · 实体机器人 (宇树 G1 等) · 2027 H2 价格回落
  • 不押宝本体 · 本体 IPO 红利期已短 · 数据闭环才是长期

§4所以 · Q4 答案 + 4-Q 系列收尾

没有"对所有人一样的行动"。
Tier 1 共同投资 + LTA · Tier 2 抢数据源 · Tier 3 等自托管 · 个人 监控 + 选场景。
这 4 种行动不对立 · 它们在 4 个层级同时发生。
知道自己是哪一层，比知道"物理 AI 卡在数据"更重要。
